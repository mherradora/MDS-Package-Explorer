What is Multidimensional Scaling?

Multidimensional Scaling (MDS) is a family of multivariate statistical techniques used to visualize similarities or dissimilarities (proximities) among a set of objects. Given a table or matrix of pair-wise distances between items, MDS positions each item in a low-dimensional target space (usually 2D or 3D) such that the resulting Euclidean distances between items reflect the empirical dissimilarities as closely as possible.

📏

Metric MDS

Assumes distances have a quantitative linear or interval relationship ($\hat{d}_{ij} = a + b \cdot \delta_{ij}$). It aims to preserve true numerical distance values directly (Classical scaling / Principal Coordinate Analysis, PCoA).

📈

Non-Metric MDS

Assumes only rank-order or monotonic relationships ($\delta_{ij} < \delta_{kl} \implies d_{ij} \le d_{kl}$). It uses monotonic regression (Shepard diagrams) to map ordinal proximity judgments into geometric space.

⚙️

Majorization (SMACOF)

Scaling by MAjorizing a COmplicated Function iteratively minimizes Stress ($\sigma(X)$) through auxiliary parabolic functions, providing guaranteed convergence without step-size tuning.

Normalized Stress Formula (Stress-1):
$$\sigma_1(\mathbf{X}) = \sqrt{ \frac{\sum_{i < j} w_{ij} \big(d_{ij}(\mathbf{X}) - \hat{d}_{ij}\big)^2}{\sum_{i < j} w_{ij} d_{ij}^2(\mathbf{X})} }$$

R and Python Multidimensional Scaling Ecosystem

This application is an explorer for packages in R and Python dedicated to Multidimensional Scaling (MDS). At the core of the R ecosystem is smacof, which implements the majorization algorithm for metric and non-metric MDS, while Python provides manifold algorithms like scikit-learn MDS, UMAP, and openTSNE.

CROSS-LANGUAGE INTEROPERABILITY

Running R in Python & Python in R (smacof ⇄ scikit-learn)

Modern data science workflows frequently combine R's specialized statistical ecosystems with Python's machine learning libraries. Below are reproducible patterns to execute R's smacof package inside Python via rpy2, and Python's scikit-learn MDS inside R via reticulate.

Python ➜ R Run R smacof inside Python with rpy2
Library: rpy2
Use rpy2.robjects and numpy2ri to seamlessly convert NumPy arrays or pandas DataFrames into R distance objects and compute MDS via smacof::mds(). 
# 1. Install prerequisite: pip install rpy2 numpy
import numpy as np
from rpy2.robjects import r, default_converter
from rpy2.robjects.packages import importr
from rpy2.robjects import numpy2ri

# Activate automatic conversion between NumPy and R arrays
numpy2ri.activate()

# Import the smacof package from R CRAN
smacof = importr('smacof')

# Create a sample symmetric distance matrix in Python
dist_matrix = np.array([
    [0.0, 2.1, 3.5, 4.2],
    [2.1, 0.0, 2.8, 3.9],
    [3.5, 2.8, 0.0, 1.9],
    [4.2, 3.9, 1.9, 0.0]
])

# Execute Metric MDS using smacof's majorization algorithm
fit = smacof.mds(delta=dist_matrix, ndim=2, type="ratio")

# Extract Stress-1 score and coordinates back into Python NumPy
stress_val = fit.rx2('stress')[0]
coords = np.array(fit.rx2('conf'))

print(f"smacof Stress-1: {stress_val:.5f}")
print("Coordinates shape:", coords.shape)
print("2D Embedding Coordinates:\n", coords)
R ➜ Python Run Python scikit-learn MDS inside R with reticulate
Package: reticulate
Use reticulate to import Python modules like sklearn.manifold directly into R, pass R matrices, and retrieve fitted MDS coordinates natively. 
# 1. Install prerequisites in R and system:
#    install.packages("reticulate")
#    reticulate::py_install("scikit-learn")

library(reticulate)

# Import the scikit-learn manifold module from Python
manifold <- import("sklearn.manifold")
np       <- import("numpy")

# Generate or load a distance matrix in R (e.g. eurodist or custom matrix)
data(eurodist)
dist_mat <- as.matrix(eurodist)[1:5, 1:5]

# Instantiate scikit-learn's MDS class with precomputed dissimilarity
mds_model <- manifold$MDS(
  n_components  = as.integer(2),
  dissimilarity = "precomputed",
  random_state  = as.integer(42),
  normalized_stress = "auto"
)

# Fit model and project coordinates directly from R
coords <- mds_model$fit_transform(dist_mat)
stress <- mds_model$stress_

cat(sprintf("scikit-learn MDS Stress: %.4f\n", stress))
print("Embedded 2D Coordinates:")
print(coords)
